# 测试用例说明

## 测试文件结构

### sample1.xlsx
- 包含员工基本信息
- 字段: ID, 姓名, 部门, 工资
- 5条数据记录

### sample2.xlsx  
- 包含项目工时记录
- 字段: 员工ID, 项目, 工时, 日期
- 5条数据记录

### sample3.xlsx
- 包含员工联系方式
- 字段: ID, 姓名, 邮箱, 电话
- 4条数据记录

## 测试场景

### 删除行列测试
1. 删除首2行测试
2. 删除尾1行测试
3. 删除指定行(2,4)测试
4. 删除首1列测试
5. 删除指定列(B,D)测试

### 同构合并测试
1. 合并具有相同结构的文件
2. 测试列对齐功能
3. 测试缺失列处理

### 连接合并测试
1. Inner Join测试 (sample1 和 sample3 通过ID连接)
2. Left Join测试
3. Right Join测试
4. NOT IN测试

## 预期结果

### 删除测试预期
- 删除操作应该准确删除指定行列
- 保持剩余数据完整性
- 正确更新行列索引

### 合并测试预期
- 同构文件应该正确合并
- 列结构应该保持一致
- 数据不应该丢失

### 连接测试预期
- 不同连接类型应该产生正确结果
- 字段匹配应该准确
- 输出应该符合SQL连接语义
